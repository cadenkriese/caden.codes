# caden.codes
This is my personal website and blog. It is built using Zola with HTML & CSS. The design is modeled after simanerush.com, but with redesigned the blog and essay pages.

I use many modern web features like grid, nesting, view transitions, AVIF, text-wrap: pretty, ch and lh units, etc. I primarily use Safari, so some features, like text-wrap: pretty as of 2026, may not work as well on other browsers. I try to keep it consistent where it matters, though. The nice thing about building with new features is that with time they will become more supported as people update their browsers.
